## Patch list

1. **Imports**: upstream absolute imports (`from common.`, `from trainer.`, `from tdmpc2 import`,
   `from envs import`) become package-relative imports.
0. Line endings: CRLF in upstream `common/logger.py` normalised to LF (diffs below are against the
   normalised upstream).
2. `common/__init__.py`: add resolve_device(cfg) helper (device from cfg.device, auto-detect)
3. `common/buffer.py`: buffer: device from cfg
4. `common/buffer.py`: buffer: public tensordict import; import resolve_device
5. `common/buffer.py`: buffer: no CUDA query on CPU
6. `common/buffer.py`: buffer: CPU storage when the device is CPU
7. `common/scale.py`: scale: import resolve_device
8. `common/scale.py`: scale: device from cfg
9. `tdmpc2.py`: agent: import resolve_device
10. `tdmpc2.py`: agent: device from cfg
11. `tdmpc2.py`: agent: Adam capturable only on CUDA
12. `tdmpc2.py`: agent: pi optimizer capturable only on CUDA
13. `tdmpc2.py`: agent: multitask discount on cfg device
14. `tdmpc2.py`: agent: cudagraph step marker only when compiling (c)
15. `trainer/online_trainer.py`: online trainer: cudagraph step marker only when compiling (c)
16. `trainer/online_trainer.py`: online trainer: public tensordict import
17. `trainer/offline_trainer.py`: offline trainer: cudagraph step marker only when compiling (c)
18. `common/layers.py`: layers.Ensemble: skip the meta-device template in Module._apply (.to() fails on torch 2.11 otherwise)
19. `common/parser.py`: parser: drop hydra runtime dependency
20. `common/parser.py`: parser: work_dir from cfg (or cwd) instead of hydra.utils.get_original_cwd()
21. `common/logger.py`: logger: row buffer for metrics.csv
22. `common/logger.py`: logger: unset (???) wandb project/entity disables wandb
23. `common/logger.py`: logger: keep save_agent when wandb is disabled (model.pt is a smoke-test artifact)
24. `common/logger.py`: logger: metrics.csv writer
25. `common/logger.py`: logger: call metrics.csv writer
26. `train.py`: train: CPU allowed
27. `evaluate.py`: evaluate: CPU allowed
28. `train.py`: train: env from cfg.env_factory dotted path
29. `evaluate.py`: evaluate: env from cfg.env_factory dotted path
30. `config.yaml`: config: drop the submitit launcher override (plugin not installed)
31. `config.yaml`: config: torch.compile off by default (c)
32. `config.yaml`: config: env_factory and device keys
